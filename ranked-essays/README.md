# Ranked essay drafts

**Rank 1 is my first recommendation.** I ranked the drafts for the combined essay and in-person presentation. I gave the most weight to a clear argument, a worked example an audience can follow, and a discussion that weighs evidence or explains a real trade-off. Draft age was secondary. The original draft link opens the folder with its presentation.

Start with **rank 1** if you would like a game-design topic with a demonstration. **Rank 2** is my first pick for software development, and **rank 3** is my first pick for programming education.
